# 🔐 Password Generator

A simple Python script that generates secure random passwords based on a user-defined length.

This project was built as part of my Python learning journey to practice functions, loops, user input validation, and the `random` module.

---

## ✨ Features

- ✅ Generates random passwords
- ✅ User chooses the password length
- ✅ Minimum password length validation (8 characters)
- ✅ Uses:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*()_+)
- ✅ Clean and beginner-friendly Python code

---

## 🛠️ Technologies Used

- Python 3
- Built-in `random` module

---

## 💻 Example Output

```
Enter the length of the password: 12

Generated Password:
G#8kP1@rTz9!
```

### Invalid Input

```
Enter the length of the password: 5

Password length should be at least 8 characters.
```
